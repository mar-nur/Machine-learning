- **Age**	

Возраст пациента (в годах)

- **Sex**

Пол пациента (1 = мужской, 0 = женский)

- **Chest pain type**	

Тип боли в груди:

🔹 1 = типичная стенокардия

🔹 2 = атипичная стенокардия

🔹 3 = нестенокардитическая боль

🔹 4 = бессимптомная

- **BP**	

Артериальное давление в состоянии покоя (мм рт. ст.)

- **Cholesterol**	

Уровень холестерина в сыворотке крови (мг/дл)

- **FBS over 120**	

Уровень сахара в крови натощак > 120 мг/дЛ (1 = Правда, 0 = Ложь)

- **EKG results**	

Результаты электрокардиограммы в состоянии покоя:

🔹 0 = в норме

🔹 1 = нарушение зубца ST-T

🔹 2 = гипертрофия левого желудочка

- **Max HR**	

Достигнутая максимальная частота сердечных сокращений

- **Exercise angina**	

Стенокардия, вызванная физической нагрузкой (1 = да, 0 = нет)

- **ST depression**	

Депрессия сегмента ST, вызванная физической нагрузкой, по сравнению с покоем

- **Slope of ST**	

Наклон пика ST-сегмента при физической нагрузке

- **Number of vessels fluro**	

Количество крупных сосудов (0–3), окрашенных с помощью рентгеноскопии

- **Thallium**	

Результат таллиевого стресс-теста (категориальный медицинский показатель)

- **Heart Disease**	

Болезни сердца:

🔹 Presence = выявлено заболевание сердца

🔹 Absence = аболевания сердца нет
